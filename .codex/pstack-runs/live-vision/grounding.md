# Grounding from pstack how

Agent Phone has a persistent control plane but no continuous image stream. Phone.mu owns leased operations and current AX/action-reference state. Bridge owns one simulator AX reader and one native input process per leased session. observe clears p.observation, reads an AX tree, captures native identities for up to 250 targets, optionally forks simctl to save a JPEG, then replaces observation and lastObservation. act consumes the current observation, validates its native identity, performs one input, then captures again. Input acknowledgment is not semantic proof.

The SwiftUI dashboard launches CLI list every five seconds. fleet queries all devices/memory and uses Phone.mu.TryLock to return lastObservation only when not busy. The card decodes the saved JPEG on view construction. This causes historical previews to disappear during operations.

Live vision must be an independent read-only data plane. Dispatch before per-phone lease expiry/validation, after exact managed-ID validation. Separate frame state and locks from Phone.mu, bridge, observation and lastObservation. Frame publication must not call observe/capture-targets/closeBridge. Leased actions retain existing semantics. Captures need explicit device, frame sequence, timestamp, dimensions, live/stale/error state, bounded bytes and overwrite/drop behavior. Stream lifetimes cannot follow control leases; control release does not stop a viewer. Shutdown/reboot/service exit must retire old streams and prevent stale frames from becoming live again. No per-frame permanent evidence files. Slow readers skip rather than queue. Dashboard decodes off main actor and limits queued main-actor publishes. MCP returns current/change frame only on request, no unsolicited continuous image messages.

Files: internal/phone/service.go owns registry, Call dispatch at232, phone lock at256, Close at210, fleet at430. internal/phone/observation.go owns actionable observation at136 and act at221. internal/phone/transport.go owns AX/input process lifecycle. cmd/agent-phone/main.go owns Unix socket server, CLI, MCP definitions and content. dashboard/AgentPhone.swift owns 5sec fleet poll and cards. Makefile builds Go and guest native helper; host capture requires separate native target.

Existing constraints: 8GiB Mac; four iOS26.5 simulators already booted, no leases. Budget6GiB admission is not hard runtime cap. Source git is unborn/all untracked. Do not alter original ../simslim or ../jev-vphone-cli. No global dependencies. Existing screenshots are retained evidence. Native APIs private and require runtime validation. Need four-stream functional/resource measurements, not assumed performance claims.

Research: .cache/live-vision-research contains official facebook/idb pinned headers and framebuffer source at1387b360a9dcad34573cb1d9f277e5a0eacfd804. FramebufferSurface.swift describes persistent CoreSimulator IOSurface + callbacks. Direct framebuffer access avoids per-frame simctl. Files are read-only research, not adopted code. A separate isolated prototype will validate the minimal host-native source before implementation.
