# Arena rubric

Score each0-5.
1. Truthful evidence semantics, no false visible success, no broadened input authority.
2. End-to-end deadline/cancellation, no late accepted result or helper race.
3. One comprehensible contract reused across CLI/MCP/matrix.
4. Minimal ownership/API surface and safe persistent helper lifetime.
5. Behavioral tests and executable real-surface verification.

Two distinct design candidates, then one independent cross-judge. Both models in one provider family.
